## Deskripsi
Proyek ini dibuat untuk mempelajari fungsi dalam Python, parameter, argumen, return value, scope variabel, serta penerapan fungsi dalam program matematika sederhana.

## Struktur Folder
- `latihan/01_salam.py` - Fungsi salam dengan parameter.
- `latihan/02_luas_persegi_panjang.py` - Menghitung luas persegi panjang.
- `latihan/03_jumlah_n.py` - Menghitung jumlah bilangan 1 sampai n.
- `latihan/04_statistik_sederhana.py` - Menghitung nilai minimum, maksimum, dan rata-rata.
- `latihan/05_scope.py` - Memahami scope variabel.
- `praktik/utilitas_matematika.py` - Program menu utilitas matematika.
- `Kuis_Formatif_Pertemuan_07.docx` - Jawaban kuis formatif.

## Cara Menjalankan
Jalankan perintah berikut dari folder utama proyek:

```bash
py latihan/01_salam.py
py latihan/02_luas_persegi_panjang.py
py latihan/03_jumlah_n.py
py latihan/04_statistik_sederhana.py
py latihan/05_scope.py
py praktik/utilitas_matematika.py
```

## Hasil Pengujian Program Utama
1. Luas persegi panjang, panjang 8 dan lebar 5: 40.0.
2. Luas segitiga, alas 10 dan tinggi 6: 30.0.
3. Jumlah bilangan 1 sampai 10: 55.
4. Faktorial 5: 120.

## Kesimpulan
Fungsi membantu memisahkan program menjadi bagian-bagian yang lebih terstruktur dan dapat digunakan kembali. Parameter digunakan untuk menerima masukan, sedangkan return mengembalikan hasil perhitungan agar dapat diproses atau ditampilkan.
